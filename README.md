# PLAYGROUND / 创意游乐场

移动端优先的互动图像实验室。参考图重设计：首页、光栅动画介绍、悬挂作品目录、编辑器与导出面板。目前开放 6 个实验：

- **光栅动画**：上传 2–8 张照片生成光栅底图与透明卡。
- **液态照片**：点一下激起涟漪，拖得越快推得越远，松手后慢慢复原。
- **无限照片**：按住持续推进，上拖加速、下拖后退，层层进入下一张照片。
- **刮刮乐**：自选封面（银、金、粉或照片）和封面文字，放入隐藏照片与隐藏的话，刮开大半自动揭晓。
- **光变卡**：2–4 张照片按柱镜条纹交错，倾斜手机按条翻转；可导出 60 LPI / 600 dpi 打印交错图。
- **密码卡**：折页（按虚线对折拼出真话）、斜视（放平从底边斜看）、红膜（红色解码镜或红色玻璃纸）三种藏法，可保存打印版。

动态文字、照片故事、裸眼 3D 已收起，代码保留但没有入口；旧的视角密码、折叠密码、颜色解密链接会跳到密码卡。

## 运行

```sh
npm run dev
```

打开 http://127.0.0.1:4173。也可用任意静态服务器托管目录；GitHub Pages 直接读取根目录。应用无运行时依赖，照片在浏览器内处理。

## 光栅动画

1. 首页选择光栅动画，点击「开始创作」。
2. 点击「图片一／图片二」或预览缩略图进入照片面板，上传 2–8 张照片；缩略图下方可排序与删除。
3. 在「参数调整」设置条纹宽度、对比度和动画方向；可直接拖动预览中的光栅，在「高级参数」中调节速度和播放。
4. 在「iPhone 相册适配」调整光栅卡缩放。
5. 导出底图、透明卡、GIF 或视频。底图及透明卡为 600 × 750，动态导出为 360 × 450。

编辑器示例四帧来自同一橘猫照片的轻微位移与旋转。上传独立照片可创建自己的逐帧动画。视频格式根据浏览器选择 MP4 或 WebM。

## 检查

开发测试使用 Playwright；安装 Chrome 后运行：

```sh
npm install
npm run check
npm test
npm run test:video
```

测试需同时运行静态服务器，默认端口 4173。可用 `PLAYGROUND_URL` 改地址。覆盖 6 个实验入口、收起与合并后的跳转、密码卡三种藏法、上传约束、排序、删除、页面返回、播放、遮罩拖动、横竖交错像素、PNG/GIF 导出、目录键盘操作、减少动态效果和 320/390/768/1440 px 布局。

检查导出文件的透明通道和 GIF 每帧解码（需要 Pillow）：

```sh
python3 tests/verify_exports.py
```

截图与测试导出文件位于忽略的 `test-results/`。

iPhone Photos 跨 App 拖动尺寸和方向传感器权限需在真实设备上验证。Live Photo 需要配对元数据及相册导入，本版本提供 PNG、GIF 与视频导出。
